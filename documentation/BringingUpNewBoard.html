Bootstrapping A New Board

These instructions assume that a download image is ready for download as described in the 'Updating Firmware' documentation.
  1. Connect the USB ports of the development machine and the Marble Mini.
  2. In a terminal window start the Xilinx virtual cable server:
        ftdiJTAG -c 30M -g 1:1
  3. Start Vivado and select the ALSUeventGenerator project.
  4. Click 'Open Hardware Manager' (or Flow->Hardware Manager menu item)..
  5. Click 'Open Target'.
  6. Click 'Open New Target...'.
  7. In the 'Open New Hardware Target' window that pops up, click 'Next>'.
  8. Set the menu to 'Connect to Local server', then click 'Next>'.  This menu item must be chosen even if the server was started on a different machine.
  9. If the desired device is not present in the 'Hardware Targets' table, click the 'Add Xilinx Virtual Cable (XVC)' button and select the IP address and port corresponding to the server started in step 2 (defaults are 127.0.0.1 and 2542, respectively).
  10. Ensure that the desired device is highlighted in the 'Hardware Targets' table, then click 'Next>'.
  11. Click 'Finish'.
  12. Click 'Program Device' (or Tools->Program Device menu item).
  13. In the 'Program Device' window that pops up, clear the 'Debug probes file' entry then navigate the 'Bitstream file' to the scripts directory in the Vitis workspace and select the download.bit file there, then click 'Program'.
  14. Once the download is complete the application will start running on the Marble Mini.
  15. Use a TFTP client to transfer the download.bit file to the Marble Mini flash memory.
  16. Set the application system parameters as appropriate.

Steps 1 through 11 apply to setting up a ChipScope session, too.  Perform them, then click 'Refresh Device'.
