Introduction

The dual event generator is based on an FPGA platform plus two FMC cards.

FMC Cards

Each FMC card provides a reference clock to the FPGA gigabit transceiver block and to an FGPA clock input, four hardware trigger inputs, an auxiliary input and a reset/recovery button input.  The trigger and auxiliary inputs are optically isolated.  Each card also provides two LVTTL diagnostic outputs capable of driving 50Ω loads.  The reference clock input is driven through an SFP optical transceiver.  The other inputs are optically isolated LVTTL levels (5V tolerant).  The auxiliary input of the first card is used to provide a pulse-per-second signal to the FPGA and the auxiliary input of the second card is used to provide a, power line monitor signal to the FPGA.

The SFP optical receiver carries the reference clock from the facility RF distribution system to the FPGA.  The optical transmitter can carry the outgoing event stream depending on the FPGA board in use.
